## 💻 1. How to Preview Locally

The web portfolio is built with native modern web standards (HTML5, CSS3, ES6 JavaScript) with **zero build step requirements**:

### Option A: Open directly in browser
Double-click `portfolio/index.html` or open it with your favorite browser (Chrome, Edge, Safari, Arc).

### Option B: Local HTTP server
Run from the root directory or inside `portfolio/`:

```bash
# Using Python
cd portfolio
python3 -m http.server 3000

# Or using Node.js / npx
npx serve portfolio
```
Visit `http://localhost:3000` to view the live interactive website.

## 🌐 2. How to Deploy Online

### Deploy to GitHub Pages (Free, 2 minutes)
1. Push your code to your GitHub repository `https://github.com/huynd4104/Care-Bridge` or create a new dedicated repo `huynd4104.github.io`.
2. In repository settings: **Settings** → **Pages** → Source: **Deploy from a branch** → Select branch `main` and folder `/portfolio` (or root if using `huynd4104.github.io`).
3. Click Save. Your portfolio is instantly live at:
   `https://huynd4104.github.io`

### Deploy to Vercel (1 click)
1. Go to [vercel.com](https://vercel.com) and import your GitHub repo.
2. Set Root Directory to `portfolio`.
3. Click **Deploy**. Vercel will give you a blazing-fast global URL with automatic HTTPS.
